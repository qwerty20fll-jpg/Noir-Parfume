# NOIR — магазин парфюмерии

Минималистичный адаптивный демо-магазин на HTML, CSS, JavaScript и Node.js.

## Что работает
- Каталог из 8 ароматов и фильтры по типу.
- Отдельные карточки товаров с визуальной подсветкой.
- Добавление товара в корзину.
- Увеличение/уменьшение количества и удаление позиции.
- Автоматический подсчёт количества товаров и итоговой суммы в сомах.
- Модальное окно регистрации с проверкой обязательных полей браузером.
- Адаптация под мобильные устройства.
- Локальный Node.js-сервер для запуска проекта.

## Запуск
1. Установите Node.js версии 18 или новее.
2. Откройте терминал в папке проекта.
3. Выполните `npm start`.
4. Откройте `http://localhost:3000`.

Также можно открыть `index.html` напрямую, но для привычного локального запуска рекомендуется использовать сервер.

## Техническое задание
### Цель
Создать современный минималистичный сайт-каталог для продажи парфюмерии с возможностью выбора товара и формирования корзины.

### Страницы и блоки
- Главная: бренд, первый экран, призыв к действию.
- Каталог: карточки ароматов, категории, цена, объём, описание нот.
- О нас: краткая информация о бренде.
- Контакты: ссылка для связи.
- Корзина: выбранные товары, управление количеством, удаление, итоговая сумма.
- Регистрация: имя, электронная почта и пароль.

### Функциональные требования
- Пользователь может просматривать каталог и фильтровать товары.
- Кнопка «Добавить» помещает товар в корзину.
- Количество одной позиции можно увеличивать и уменьшать.
- Товар можно удалить из корзины.
- Сумма пересчитывается автоматически.
- Регистрационная форма проверяет обязательные поля и минимальную длину пароля.
- Интерфейс адаптируется для смартфонов, планшетов и компьютеров.

### Дизайн
- Тёмная палитра, акцентный цвет шампань/золото.
- Минималистичная типографика и большие заголовки.
- Карточки товаров с мягкой подсветкой.
- Плавные переходы, адаптивная сетка, доступные подписи кнопок.

### Важно перед реальным запуском
Это демонстрационный фронтенд. Регистрация не создаёт аккаунт на сервере, корзина хранится только в памяти вкладки, оформление заказа и оплата не подключены. Для production-версии потребуются API, база данных, безопасное хеширование паролей, серверная валидация, обработка заказов, платёжный провайдер, доставка, политика конфиденциальности и защита от злоупотреблений.
